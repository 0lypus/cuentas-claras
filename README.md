## ✨ Funcionalidades
- Grupos con link de invitación
- Reparto equitativo, por porcentaje o por ítem
- Simplificación de deudas (algoritmo de grafos)
- Gastos en pesos y dólares
- Resumen listo para WhatsApp
- Instalable como PWA
